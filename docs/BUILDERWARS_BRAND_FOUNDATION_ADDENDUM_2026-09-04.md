# BuilderWars Brand Foundation Addendum

Status: **ADOPTED — owner ruling, 2026-09-04**

## Why this is an addendum

The accepted local foundation binds exact byte digests for the platform charter, entity model, brand/domain migration, and domain cutover contract. Rewriting those accepted artifacts merely to modernize presentation would invalidate their evidence chain.

This addendum changes the public naming decision without altering historical bytes. It is authoritative for new public presentation and must be read after these preserved foundation artifacts:

- `BUILDERWARS_PLATFORM_CHARTER.md`
- `BUILDERWARS_ENTITY_MODEL.v1.json`
- `BUILDERWARS_BRAND_DOMAIN_MIGRATION.md`
- `BUILDERWARS_COM_DOMAIN_CUTOVER_CONTRACT.md`

## Superseding rulings

1. **BuilderWars** remains the sole public umbrella.
2. **Arena, Forge, Games, Evals, Leagues, Studio, Watch, Academy, and Passport** are the adopted public category names.
3. **AgentWars** and **BuildWars** no longer name public sub-products. They remain only where historical provenance, immutable evidence, schemas, protocols, paths, or code compatibility require the strings.
4. **builderswars.com** is confirmed as the defensive plural zone and is intended to redirect to `builderwars.com`; it never becomes a separate product.
5. These changes do not elevate any foundation artifact from local acceptance to deployment or launch proof.

The complete rules and current domain evidence live in [`BUILDERWARS_BRAND_ARCHITECTURE.md`](BUILDERWARS_BRAND_ARCHITECTURE.md).
