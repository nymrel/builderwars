## Activation sequence

1. Prove protected runtime configuration for the exact integrated source.
2. Prove source-bound deployment, served-byte parity, canonical origin, and a
   tested rollback target without changing BuilderWars.com apex or `www` unless
   that exact action is separately authorized.
3. Complete the consented tester, cleanup, detached review, and launch-authority
   ceremony.
4. Rebuild `robots.txt` and a sitemap for the verified origin; do not edit the
   prelaunch files in place without a source change and new evidence pack.
5. Add canonical, social, and structured-data declarations only when their URLs,
   entities, claims, and actions match the served application.
6. Re-run local, browser, accessibility, security, and discoverability checks;
   then bind the outputs to a new exact-source launch pack.
