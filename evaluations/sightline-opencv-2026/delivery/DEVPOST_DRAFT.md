## Title
Sightline

## Tagline
See visual defects, bound the decision, verify the outcome.

## Inspiration and intended user
A page can load successfully while its most useful proof, control or content has disappeared. Sightline helps developers turn visual differences into an auditable next decision while retaining release authority.

## What it does
Sightline compares a baseline and candidate screenshot with substantive OpenCV 5 image analysis. Typed findings drive deterministic policy: accept no material change, request human approval, or reject unbounded input. The planner has no product-write or deployment tool.

Our demonstration uses the existing BuilderWars Arena. A controlled hidden receipt produces 54 retained components and 62,432 changed pixels. An unapproved restore is rejected. A separate isolated fixture controller consumes one candidate-bound, one-use scripted demo event and restores the injected property. A fresh screenshot then matches the baseline exactly and a new OpenCV pass returns zero findings. The scripted event is clearly labeled; it is not a claim of real human approval or production authentication.

## How we built it
OpenCV 5.0.0 performs PNG decoding, absolute difference, grayscale conversion, thresholding and connected-component extraction. Python dataclasses hold typed evidence; deterministic policy and SHA-256 traces preserve reproducibility. Browser tests render tracked Nymrel source on loopback. The exact CPython 3.12/Linux x86_64 dependency lock pins OpenCV and NumPy wheel hashes. The existing bounded Lambda-compatible handler is a source packaging path, not evidence of cloud execution.

## Results and failures
The merged Stage 1 hosted record has 35 passing tests and 24 controlled browser executions across Chromium and Firefox. The local journey extension has 39 passing tests. A fresh current-main Firefox run covers twelve cases: ten true positives and two true negatives. These tiny controlled sets do not establish production accuracy or representative traffic.

We retain the earlier fragmented-materiality miss, below-fold mobile framing error, reversed synthetic polarity and repaired compressed-PNG expansion vulnerability. Malformed PNG, mismatched dimensions and oversized declared dimensions are rejected. We have not measured time savings, detection uplift against a simpler diff baseline, general repair success, cloud latency or cost.

## AI and agent use
The running loop uses deterministic computer vision and policy, not an LLM. OpenCV findings change the later approval decision. Codex assisted with source review, test execution, documentation and demonstration preparation. AI coding assistance alone is not the claimed Agentic Vision mechanism. The demonstration controller has no production authority.
